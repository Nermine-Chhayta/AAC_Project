# My AI Coding Playbook

## 1. When I reach for AI first
- planning a feature
- writing user stories
- business rules
it was so helpful to plan well before asking AI to write code for m, when  we first used ChatGpt to generate user stories so then when we use cursor for the backend it all makes sense 

## 2. When I do not reach for AI
- manual checking and testing
- reviewing
- personal reflection
I always have to check myself the accuracy of what AI generates and if it matches the needs of my app and has my business logic 

## 3. My non-negotiables
- I lead AI
- context is a must
- good prompt leads good output

## 4. My review rules
- check if things make sense
- check what AI claims as true is actually true
- I don't believe tests pass without evidence and trying to break them to actually see if they're coherent 

## 5. What I am still figuring out
- knowing exactly what to trust AI for and what not
- trying to reduce credit use
- if there's one tool that captures the use of many others for subscription purposes

---

## Decision Card
- For a new feature I reach for: ChatGpt
- For a code review I reach for: Cursor
- For debugging I reach for: Copilot
- For infrastructure I reach for: Claude code CLI
- I will never paste credentials into an AI tool.
- My one rule is: I own my code and my logic
